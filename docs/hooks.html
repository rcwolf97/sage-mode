Sage Mode / Hooks

Hooks

hooks.json is empty. Sage Mode does not inject a skill at session start. Unslop is a rule, not a SessionStart hook.

hooks/run-hook.cmd is still there if you add a hook later. Scripts must be extensionless so Windows does not prepend bash.

If you add a hook

Register it in hooks.json and hooks-cursor.json. Point at run-hook.cmd plus an extensionless script. Quote the plugin root. Set "shell": "bash". Do not restore SessionStart skill injection. Trust hooks/run-hook.cmd over any writeup.
