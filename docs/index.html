sage-mode

A Cursor plugin for going from idea to shipped feature in a day — and a notebook that remembers how.

Five people built agent-engineering toolkits and all five converged on the same spine. None of them optimizes for shipping today, and none of them can find what it learned last week. sage-mode is the synthesis: a narrow spine that always runs, a searchable catalog that never costs you a token until it's needed, hooks that can actually veto the agent — and this notebook, which is both what you read and what the agents search.

In plain terms: This page is the front door. Design holds the blueprint we're arguing about. Research holds the teardowns of the five repos it's built from. As the project runs, Plans, Reviews, Experiments and Learnings fill in below — every artifact sage-mode produces lands here as a page.
